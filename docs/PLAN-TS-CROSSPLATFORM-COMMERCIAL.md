# ClaudeSync TypeScript 跨平台与商业化计划

## 0. 这轮要解决什么

迁移前 ClaudeSync 使用 Python、Tk 和浏览器回退。当前 v2 本地源码的界面与核心已统一到 Pie 的主技术栈：TypeScript、React、Vite、SwimmerUIKit、SwimmerI18nKit；桌面用 Electron，适合手机的产品用 Capacitor。

这份计划先服务 ClaudeSync，也作为 MatrixAPPs 后续小工具的样板。核实到 2026-10-11，[v1.3.3 仍是最新公开版](https://github.com/PieAIStudio/ClaudeSync/releases/latest)；新技术线以 v2 为边界，不在重构过程中破坏旧版。公开 v1 安装包保留；当前源码只维护 TypeScript 新版核心，v1 行为参照保存为冻结夹具和历史证据。

本文跟踪 ClaudeSync 的 TypeScript / Electron 工作。MatrixAPPs 共通收费决定以 HQ 的[商业模式](../../../../HQ/1-what/business-model.md#matrixapps)和[技术方向](../../../../HQ/docs/canon/pie-product-technology-stack.md#matrixapps)为准；组合阶段表在 [MatrixAPPs 多端与收费路线](../../../docs/plans/active/PLAN-MATRIXAPPS-CROSSPLATFORM-CHARGING.md)。

## 1. 方向约束（GoalCascade）

### 产品角色

- ClaudeSync 当前角色：可信的本地桌面工具与 TypeScript 品牌界面样板；现有公开版仍免费，新测试线不擅自改变它的商业角色。
- MatrixAPPs 组合角色：按 HQ 已批准的三种角色逐个判断——低价收费、免费引流到 SwimInAI、自用。统一支付体验只适用于确实选择收费的产品，不能把“矩阵统一”理解成每个工具都必须收钱。
- 目标用户：在一台电脑上使用多个 Claude Code 账号、需要安全整理本地会话索引的人。
- 非目标用户：只使用手机、没有电脑 Claude 本地数据的人；他们不能从当前 ClaudeSync 核心功能中获得真实价值。

### 商业边界

- ClaudeSync 的公开稳定版继续免费；TypeScript v2 测试线也不擅自改变这个角色。
- ClaudeSync 是桌面工具，不接手机内购 SDK、不做手机空壳；按 MatrixAPPs 口径，免费版放广告、付费版去广告，统一经共享 AdKit 接入，不另接追踪 SDK。
- MatrixAPPs 的共通免费档、5 次温和提示、RevenueCat、广告（免费放、付费去）和跨平台收费边界，以 [HQ 商业模式](../../../../HQ/docs/canon/portfolio/business-model.md#matrixapps)、[HQ 技术方向](../../../../HQ/docs/canon/pie-product-technology-stack.md#matrixapps)和[组合计划](../../../docs/plans/active/PLAN-MATRIXAPPS-CROSSPLATFORM-CHARGING.md)为准。

### 产品与平台边界

- ClaudeSync 的桌面版必须能访问本机文件和 Claude 进程，因此 Electron 主进程拥有文件与系统能力，React renderer 只能调用白名单 API。
- 浏览器版可以用于演示和无本地权限的界面检查，不能冒充完整 ClaudeSync。
- 手机版只有在定义出真实的手机任务后才进入开发；“把桌面同步工具包成手机网页”不算完成。

## 3. 每阶段的反思问题

每完成一个阶段，回答：

1. 这一步是否证明了用户真的得到价值？
2. 有没有为了“全平台”加入没有真实用途的代码？
3. 免费用户是否仍能完成第一次核心任务？
4. 付费提示是否说明了交换内容，而不是制造焦虑？
5. 哪个下一阶段应该被删掉、降级或暂停？

本轮复盘：

1. 合成数据证明了同步计划和新旧核心一致；真实用户价值和真实数据同步还没有证据。
2. ClaudeSync 手机上没有独立任务，所以去掉手机壳；不能为了统一外观给它加没有用处的手机包。
3. ClaudeSync 公开版与 v2 测试线都继续免费，符合当前产品角色。
4. MatrixAPPs 的免费体验、付费边界、广告和 RevenueCat 试点由组合计划及 HQ 唯一来源维护。
5. ClaudeSync 继续完成桌面打包证据；需要签名和公证的工作留到开发者凭证可用时。

## 4. 停止条件

- TypeScript 与冻结的 v1 夹具结果无法解释地不一致。
- Claude 索引格式发生未知变化，无法安全判断写入目标。
- 手机版没有独立、真实的手机任务。
- 桌面包存在无法解释的数据风险或旧版无法回滚。
