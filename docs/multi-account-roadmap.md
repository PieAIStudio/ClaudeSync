# ClaudeSync 多账号升级路线

这份文件记录多账号功能的目标、边界和验证结果。它是维护者用的路线图，不是用户必须阅读的操作说明。

## 目标

把“两个账号互相同步”升级为“自动发现的多个账号组成一个可检查的本地会话集合”。每个账号仍然是一个独立的 Claude 本地索引目录；同步时只传播通过安全检查的本地入口，不复制聊天正文，也不迁移云端资源。

## 迭代编排

| 阶段 | 工作 | 完成条件 |
| --- | --- | --- |
| 1. 数据模型 | 默认扫描索引根目录下的所有 UUID 账号目录；保留旧的两账号配置读取方式 | 旧配置仍可打开；重复目录或名称会被明确拒绝 |
| 2. 同步计划 | 从“两两互推”改为目标账号去重的并集计划 | 同一 `cliSessionId` 在同一目标只出现一次；分支入口仍使用确定性 ID |
| 3. 标题策略 | 汇总同一会话在各账号的标题；安全时传播唯一手动标题；多个手动标题时让用户选任意账号或跳过 | 标题正文不被改写；明确选择后才覆盖手动标题 |
| 4. GUI | 首次打开自动显示发现的账号；只有发现不完整时才显示添加账号的补救区域；标题明细显示账号标题候选 | Tk、浏览器回退和共享 Mac GUI 都能检查与同步 |
| 5. 文档与视觉 | README、流程图、预览图按语言提供对应文字；维护地图和变更记录同步更新 | 各语言页面不混用解释性语言，专业文件名保持原样 |
| 6. 发布 | 更新测试矩阵、安装包、Release 说明 | 本地测试、跨平台 CI、安装包构建和公开 Release 全部通过 |

## 选择的边界

- 默认自动发现至少 2 个账号；手动补救设置允许更多账号，并用安全上限防止误选过大的父目录。
- 同一会话会传播到每个配置的目标账号，但同一目标账号只新增一次入口。
- 任一账号的删除标记会阻止该会话继续传播，避免“被删除内容复活”。归档、远程、定时任务和缺正文记录仍按原规则跳过。
- 标题冲突按会话聚合。用户可以选择任意账号的标题，工具再把选择应用到其他需要更新的账号；选择“跳过”只跳过标题，不阻止安全的会话入口同步。
- 登录、切号、聊天正文、Artifact、评论监控、连接器和 Cookie 不属于本项目的同步范围。

## 回滚方式

配置文件保持 JSON 结构并保留 `accounts` 数组；旧的两账号配置仍是合法输入。每次写入前继续生成备份和 manifest；如果新版本发现未知索引结构，会停止写入而不是猜测。

## 当前验证

- 本地：50 项会话、平台、配置和多账号测试通过；浏览器页面脚本通过 Node 语法检查；Tk/浏览器标题选择路径已做冒烟检查。
- CI：Ubuntu、Windows、macOS × Python 3.9/3.12 的 6 组检查全部通过。
- 发布：[`v1.3.2`](https://github.com/PieAIStudio/ClaudeSync/releases/tag/v1.3.2) 已生成 macOS arm64/x64、Windows x64、Debian/Ubuntu amd64 和 Linux tar.gz 安装包。
- 视觉：英文、日文、西班牙文、葡萄牙文各有对应预览图和流程图；共享 GUI 的语言切换会重新渲染当前结果。
