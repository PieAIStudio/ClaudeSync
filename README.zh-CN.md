# ClaudeSync

[English](README.md) · [日本語](README.ja.md) · [Español](README.es.md) · [Português](README.pt-BR.md)

ClaudeSync 帮你看清并整理同一台电脑上几个 Claude Code 账号的本机聊天，以及当前账号的云端 Code 历史。角色：免费、自用优先。技术：TypeScript + React + Electron，使用 SwimmerUIKit 与 SwimmerI18nKit。状态：v2 本地测试版；尚未公开发布，公开 v1 安装包仍在 [GitHub Release](https://github.com/PieAIStudio/ClaudeSync/releases)。

## 怎么用

1. 双击 `ClaudeSync.app`，或源码目录的 `Sync.command`。点“重新检查”。
2. 左边勾选要处理的账号，点击账号名称就能看它的聊天；“所选账号的全部聊天”会合并显示并去重。
3. 搜索或筛选，勾选聊天。同步、归档等操作先预览；**删除选中的聊天**只弹简单确认窗口，写清邮箱、条数和聊天状态，确认后直接删除，不建删除备份、不可撤销。
4. 修改本机聊天前，保存并完全退出 Claude / Claude Code。查看某个账号时，删除只针对这个账号；云端历史请切到“云端聊天”，它只读取当前登录账号，云端删除不用关闭 Claude。

**只想几个账号都留下同样的 10 条？** 勾选你要的 10 条，点“各账号只保留所选”。程序先确保它们能补到每个所选账号，再把其他聊天归档。也可以点“选最近 10 条可同步聊天”，检查选择后再操作；它不会自动执行整理。

账号里还有活跃的远程或定时任务时，“只保留所选”会停止；先在 Claude 里处理这些任务，再整理普通聊天。

像整理书架：勾选的书放到每个书架，其他的收进抽屉；以后还能拿出来。

## 可以做什么

| 操作 | 结果 |
| --- | --- |
| 同步所选 | 补齐所选账号缺少的聊天入口；标题不同可以先选择 |
| 各账号只保留所选 | 补齐所选聊天，取消它们的归档，归档其余聊天 |
| 归档 / 取消归档 | 从普通列表收起 / 放回，保留正文与项目 |
| 改标题 | 给同一聊天在所选账号的副本改名，一次一条 |
| 收藏 / 取消收藏 | 修改收藏标记，便于筛选 |
| 删除选中的聊天 | 删除所选本机聊天、同账号的已配置旧副本和无人共用的主正文；不删除账号或项目，不创建删除备份 |
| 云端聊天 | 当前登录账号的云端 Code 历史，包括 Wakeup；可多选删除已验证、空闲且无关联任务的记录 |
| 备份与恢复 | 只用于其他本机整理操作；删除不提供恢复，旧备份不会自动清理 |

搜索包括标题、不同账号的标题、项目路径和聊天 ID。筛选包括未归档、已归档、可同步、暂不能同步、已收藏。筛选隐藏的已选聊天仍会参与操作，界面会提醒；“取消选择”清空全部选择。

如果一条聊天的历史还被另一条聊天或未参与整理的目录使用，删除会停止，并建议归档，避免影响其他聊天。

## 数字和邮箱

“4 条本机聊天 · 21 条本机归档”是数字含义的例子：名单里有 4 条未归档，21 条已收起来。同一聊天只数一次。已核实资料目录的账号使用 Claude 资料服务确认的组织目录，旧目录的副本不混入，也不会把已归档的聊天算回未归档。本机和云端检查都会保存已核实的邮箱与组织；旧版本只记了邮箱的账号，需要登录后再检查一次才能核实目录。尚未核实目录的账号按保存的本机资料显示，未必等于 Desktop 当前列表。

macOS 上“重新检查”通过 Claude Desktop 现有的仅限资料读取授权查询当前邮箱与组织 ID，不使用 CLI 登录冒充 Desktop。验证结果只记在本机；验证失败或切号时清除当前登录标记。本机查看和整理仍能离线使用；Windows/Linux 自动 Desktop 验证暂未支持。发现遗漏的当前账号只补入 ClaudeSync 配置，保留参与勾选，不修改 Claude 文件。

“本机聊天”和“云端聊天”分别计数、分别选择，不能直接相加。云端只读当前已核实账号和组织，用现有且未过期的 Code 会话授权，显示返回的前 100 条；达到上限时明确提醒。这些第一方联网读取是小工具默认离线的维护例外，无自建后端、模型调用、广告、追踪或支付 SDK。

## 删除与保护

删除确认按状态提醒：普通聊天可取消并归档；已归档聊天可取消并继续保留；混合选择分别说明。删除没有文件修改预览、删除备份、回收站副本或恢复按钮。想保留请使用归档。

本机删除会移除选中的记录、同账号已配置的旧副本、相关归档提示，并添加原生删除标记；无人共用的主 JSONL 正文直接删除。先检查整个会话根目录下的账号，包括设置里没纳入的账号，保护共享历史。其他聊天仍使用的正文、项目、worktree 和辅助 CLI 文件保持原样；同账号未参与目录仍占用记录 ID 时停止删除。所有本机写入仍检查进程、配置、正文指纹、目录清单和快照，持有锁、原子修改并核验。中断时如实提示部分完成，不承诺恢复删除。

云端删除只向当前已核实账号和组织的选中 Code 会话 ID 发 DELETE；写前重新读取状态，每个请求校验登录与授权有效期，失败立即停止，读取结果核实完成数，结果未知不重试。运行中、关联任务、模板和未知格式只显示原因，不能在这里删除。不调用定时任务设置接口，不登记设备、不刷新授权，不直接改 Claude 数据库。内置接口会随 Claude 版本变化；真实云端读取已验证，验收没有删除用户聊天。

其他本机整理继续预览、备份并提供受保护恢复。既有配置和旧备份不自动清理。设置、邮箱与组织对应关系存在系统的 ClaudeSync 资料目录，凭证只在主进程内存中使用，绝不写入 IPC、日志或备份。请勿将私有配置、备份、报告或真实聊天截图上传公开 issue。

## 开发

需要 Node 24 和锁定版本的 pnpm。已安装依赖的本机直接运行；新 checkout 用 `pnpm install --frozen-lockfile`。

```sh
pnpm dev
pnpm typecheck
pnpm test
pnpm build
pnpm package:mac:dir
```

`pnpm dev` 默认打开 Electron。测试只改临时合成数据。开发版可用 `CLAUDESYNC_DATA_DIR` 指定隔离的应用资料目录；正式安装包忽略这个覆盖项。

当前本机包为未签名 Apple silicon `.app`；Windows、Intel Mac、Linux、签名与公证仍需单独验收。界面保留五种语言。不接广告、追踪、内购或后台自动同步。提交代码不会触发云端 CI 或发布，CI 只接受手动启动。
