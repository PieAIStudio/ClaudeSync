# ClaudeSync

[中文](README.zh-CN.md) · [English](README.md) · [Español](README.es.md) · [Português](README.pt-BR.md)

同じコンピューター上の複数 Claude Code アカウントのセッション一覧を表示・整理します。無料、自分で使うことを優先。TypeScript + React + Electron、SwimmerUIKit / SwimmerI18nKit。v2 はローカルのプレビュー版で、未公開です。公開 v1 は [GitHub Releases](https://github.com/PieAIStudio/ClaudeSync/releases) に残っています。

## 使い方

1. `ClaudeSync.app` またはソースの起動スクリプトを開き、再読み込みします。
2. 対象アカウントにチェック。名前をクリックすると、そのセッションを表示します。全体表示では重複を数えません。

各アカウントに同じ10件を残すには、その10件を選んで「各アカウントに選択分だけ残す」。不足分を追加し、選択分のアーカイブを解除し、残りをアーカイブします。必要な本文が不足している場合などは、他のセッションを保管する前に停止します。「最近の同期可能な10件を選択」は選択だけで、変更しません。

利用中のリモート・定期タスクがある場合も、この操作は停止します。先に Claude 内でそのタスクを整理してから、ローカルセッションを整理してください。

## 削除と件数

「選択したセッションを削除」は選択した会話を削除し、アカウントは削除しません。短い確認画面で、利用中ならアーカイブ、保管済みならキャンセルして保持するよう案内します。独占本文はシステムのゴミ箱へ移し、ゴミ箱から戻せます。端末では選択したグループとアカウントだけを対象にし、隠れた旧コピーへ拡大しません。他の会話が使っていない主 JSONL 本文を対象にします。共有内容、プロジェクト、worktree、補助 CLI ファイルは保持し、本文をすべてゴミ箱へ移してからインデックスを更新します。他の整理操作は従来通り事前確認・バックアップ・復元に対応します。

確認済みアカウントの件数はプロフィールが確認した組織の一覧を使い、旧コピーは現在のアーカイブ状態を上書きしません。メール・組織は端末だけに保存。端末とクラウドの両方の確認で組織を記憶します。旧版のメールだけの記録は、そのアカウントにログインして一度再確認し、組織を確定する必要があります。端末とクラウドは別々に数え、選択します。クラウドは現在のログインの Code 履歴（Wakeup を含む）、最大100件。既存の未期限切れ会話権限で読み、確認済みの空いている Remote Control 記録だけ削除。実行中・関連タスク・未知形式は不可。書き込み前に再確認、失敗で停止、読み直して結果を確認。OAuth 更新・デバイス登録・定期タスク設定変更・自動再試行は行いません。端末変更前は Claude を終了、クラウドでは終了不要。認証情報は main メモリーだけに置きます。クラウド読み込みは実機確認済みですが、受入確認で実ユーザーの会話は削除していません。

macOS のキーチェーンは保守中の `@napi-rs/keyring` が ClaudeSync 内で非同期に読み取り、共有 CLI を使いません。確認ダイアログにアプリ側の応答期限はありません。同じ起動中、ログイン・暗号化キャッシュが変わるまで確認とメモリー内の認証情報を再利用します。現在の組織の確認は、他の組織から退会した証拠ではありません。明示的な退会証拠がない別組織は未確認のまま、旧コピー整理では移動も取り込みもしません。現在のプロフィール取得では退会を証明できません。

端末の未知の項目は触らずスキップし、確認事項にパスと「スキップ済み、変更なし」を表示します。既知の Desktop `backlog`・`waiting-input` は警告せず保持し、管理対象にしません。未知の共有参照があり得る場合、削除は本文を保持します。実際の書き込み先が危険な場合や関連本文が変化した場合は、その操作を停止します。

## 開発

Node 24 と固定 pnpm を使用。初回のみ `pnpm install --frozen-lockfile`。

```sh
pnpm dev
pnpm typecheck
pnpm test
pnpm build
pnpm package:mac:dir
```

テストは一時的な合成データのみ使用。開発版は `CLAUDESYNC_DATA_DIR` で分離できます。配布用ビルドはこの指定を無視します。

現在のローカルパッケージは未署名 Apple silicon `.app`。他の OS、Intel Mac、署名と公証は別途確認が必要。5言語 UI。現在の版には広告・追跡・課金・自動同期はありません。CI は手動のみ。旧 Python/Tk/Web コードは現在のソースから整理しましたが、Git 履歴と旧公開版は保持しています。
